# Upstream source

This English edition derives from [Ajan Atölyesi](https://github.com/OrcunSamiTandogan/ajan-atolyesi) at [`76553e6`](https://github.com/OrcunSamiTandogan/ajan-atolyesi/commit/76553e66ddf4b0f3ab9e284b9bfcea0744fd225c). The original MIT license and copyright notice are preserved in [LICENSE](LICENSE).

The English edition localizes the launcher and setup documentation. It keeps the upstream command names, storage identifiers, and tmux session conventions for compatibility. It is not a side-by-side installation profile: installing it over the same location may replace the existing workshop launcher. Pick one edition per local installation and do not reset or recreate an existing profile just to switch languages.

When updating this edition, review differences from the upstream revision, keep the route-specific prompts and UI strings in sync, and rerun the verification steps before publishing.
