# First Pi task: make a Turkish slug

Try this in a disposable copy of this repository, after you have verified the provider connection yourself. The exercise starts with one deliberately failing test. No extra packages or keys belong in the task prompt.

> Only edit `demo/slug.py`, and `demo/test_slug.py` if you need to add a test. Update `slugify` to transliterate Turkish letters to ASCII, join words with a single hyphen, and remove leading or trailing hyphens. Example: `İstanbul, Çağrı ve Işık!` → `istanbul-cagri-ve-isik`. Keep existing tests. Run `python3 -B -m unittest discover -s demo`. Report the change and actual test outcome. Do not install packages, edit outside this folder, or publish anything.

This is a Pi file-editing exercise. DSH in this setup is text-only.
