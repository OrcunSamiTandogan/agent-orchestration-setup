# Changelog

## Setup reliability

- Pi no longer launches a different local profile when no NVIDIA key was saved in the app.
- DSH CLI verifies the exact tmux session and leaves older or unrelated sessions alone.
- DSH Web distinguishes a browser launch request from an opened window.
- Added a first-run checklist, manual Agensi route, and platform verification notes.


## English derivative

- English onboarding, platform guides, and separate copyable Claude Code and Codex prompts.
- Choose Pi and DSH, Pi only, or DSH only.
- The setup guide separates installation, launcher verification, and optional live provider usage.
- macOS and Windows/WSL are explicitly labeled previews.

Upstream implementation and version history are in [Ajan Atölyesi](https://github.com/OrcunSamiTandogan/ajan-atolyesi). The version file is not proof of a GitHub Release.
