# Report a security issue

Please do not post exploit details, credentials, private files, or real session logs in a public issue or pull request. If private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise, raise a minimal public issue asking for a private contact method without describing the issue. Include the release or commit, platform, and impact when using a private channel.

Agent Orchestration Setup is a terminal launcher, not a security boundary. Start agents only in folders you trust and keep ordinary permission prompts enabled. Enter provider keys locally in the app. Do not include keys in the repository, the Agensi package, or screenshots. If a key is exposed, revoke or rotate it in the provider's own dashboard.
